# Langton's Ant
A straightforward implementation of Langton's Ant using Python and Pygame. The simulation logic is decoupled from the rendering engine.

## Installation & Usage
Clone the repository and install the requirements:
```bash
git clone https://github.com/alireza2317/langton-ant.git
cd langton-ant
uv sync
```

And simply run the simulation:
```bash
uv run main.py
```

## Controls
Up/Down: Adjusting simulation speed
Q: Quit
